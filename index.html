about

Researcher & builder

I'm a junior undergraduate studying Electrical Engineering at the University of Texas at Arlington, doing research at the Autonomous Control Lab at the intersection of control theory, robotics, and embedded electronics.

My current research focuses on autonomous aerial vehicles — specifically designing and validating cascaded LQR position controllers for the Crazyflie 2.1 quadrotor, from Gazebo simulation through Vicon motion capture.

Outside the lab I build AI-driven applications, real-time hardware systems, and tools that make complex workflows simpler. I like problems where theory and physical reality have to agree.

Selected work

Cascaded LQR Position Controller — Crazyflie 2.1

Outer-loop position controller using cascaded LQR design, validated first in Gazebo simulation then on real hardware via Lighthouse and Vicon motion capture. Ongoing research targeting CDC publication, with IRL/SPSA-based parameter adaptation.

Python ROS2 Gazebo LQR Vicon Research

Hand-Gesture Robot Car

Real-time gesture-controlled robot car using MediaPipe hand-tracking and OpenCV. A PyTorch variant trains a custom gesture classifier. Wireless control over Bluetooth between Raspberry Pi and Arduino.

Python PyTorch OpenCV MediaPipe Arduino RPi
↗

Personalized News Chatbot via Email

AI email assistant that delivers daily personalized lessons and real-time news summaries to users on any topic they choose. Built with n8n automation, Gemini, Reddit, and NewsAPI — zero-touch once configured.

n8n Gemini Google Sheets NewsAPI Reddit API

Motion-Triggered Security Camera

Lightweight Python script that monitors a webcam feed, detects motion using background subtraction in OpenCV, captures a frame, and immediately dispatches an alert email with the image attached.

Python OpenCV SMTP
